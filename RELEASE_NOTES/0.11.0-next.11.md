## New
- Enso now asks before closing a tab that still has something running, or that's holding an agent conversation it would discard.
- Settings has switches for both confirmations, and for agent notifications — including keeping them quiet while you're already in the app.

## Fixed
- Deleting a space asks first, and cleans up the agent conversations it was holding instead of stranding them.
- Temporary tabs no longer expire out from under you while they're on screen in a split.
- Putting a tab to sleep no longer leaves a stray notification behind a moment later.
- Escape closes the confirmation dialogs again.
- The command palette no longer offers ⌘W beside Put Tab to Sleep — that shortcut closes.
- Sweeping across a pane's controls no longer makes the tooltip blink out between them.
